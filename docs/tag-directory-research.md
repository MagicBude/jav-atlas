# JavDB 与 minnano 类别目录核实

核实日期：2026-10-23。目录是当日接口快照，不保证包含所有历史或隐藏类别。

## JavDB 的类别身份与分组

实测移动接口 v2/tags，type 参数为数字 0 至 4，五次请求均返回 HTTP 200。排除 main/year/month/duration 等非类别筛选后，各类型返回 307、151、208、55、123 个类别条目，共 844 个，分属 25 个带内容类型的分组。分组名称共有 10 种。

**类别 ID 只在内容类型内有意义，不能跨类型直接合并。** 844 个条目的数字 ID 只有 327 个不同值，但这不代表只有 327 个类别。例如 ID 109 在有码目录表示“戀乳癖”，在欧美目录表示“泳池”。将它们按数字 ID 合并会导致错误显示名称、错误分组和筛选串选。此前按数字 ID 合并的实现和“327 个类别”的结论已撤回。

来源快照位于 relay/javdb/tag-catalog.json，schemaVersion=2，entries 以“type:id”为键，保留原生 id、type、name；groups 保留各类型的来源分组与名称。complete=false。原始接口响应留在本机 .cache/javdb-tags-0.json 至 4.json。

## 网页词典与查询

web/src/data/javdb-tag-labels.json 以“type:id”为键，含 label/sourceNames/status，共 844 项。当前先沿用来源名称，标记 source-label；先前在合并身份上维护的显示别名撤回，避免把一个类型的词套给另一个类型。没有使用外部翻译服务，也没有翻译标题和评论。

目前作品记录没有可靠的类别内容类型字段。entities/tagLabels.ts 因此同时核对来源数字 ID 与原名称，只有显示名一致时才采用词典名称；查不到或存在歧义就保留原文。分组也要求 ID 与原名同时匹配，且所有候选类型指向同一个分组；否则列入“未确认分组”。作品名称的简繁差异也可能使其暂未归组，不能为减少未确认项而凭空猜测类型。

网页新查询键使用“原生 ID＋编码后的原名称”，仅用于浏览条件，不修改采集数据的 ID。名称中的逗号经过编码，避免破坏多选分隔。同号不同名称的选项、计数、详情链接与筛选彼此隔离。旧数字链接仍按旧的数字匹配语义运行，并在筛选面板明确注明未区分原名；重新选择具体类别即可生成精确链接。

目录只定义分组，数量来自当前入口的本地作品集合。没有本地作品的类别不列出，已选零数量条件保留。维护词典时，必须在对应内容类型内核对原名称，不能只凭数字 ID 修改 label。

## minnano 的观察范围

通过本机代理访问 actress_list.php 与 av_list.php，取得有效标题与 HTML。人物目录出现 112 次标签链接，按 tag_a_id 去重为 38 个。这些是当前人物条目的观察标签，不能称为全站目录。作品列表页未发现 tag/genre 链接，也不能据此断言源站没有作品类别。

minnano 人物标签与 JavDB 作品类别分别维护，不能按同名或同号自动合并。本轮没有建立 minnano 全量类别目录。
