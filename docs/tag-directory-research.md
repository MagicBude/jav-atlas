# JavDB 与 minnano 类别目录核实

核实日期：2026-10-23。目录是当日接口快照，不保证包含所有历史或隐藏类别。

## JavDB 的类别身份与分组

实测移动接口 v2/tags，type 参数为数字 0 至 4，五次请求均返回 HTTP 200。排除 main/year/month/duration 等非类别筛选后，各类型返回 307、151、208、55、123 个类别条目，共 844 个，分属 25 个带内容类型的分组。分组名称共有 10 种。

**类别 ID 只在内容类型内有意义，不能跨类型直接合并。** 844 个条目的数字 ID 只有 327 个不同值，但这不代表只有 327 个类别。例如 ID 109 在有码目录表示“戀乳癖”，在欧美目录表示“泳池”。将它们按数字 ID 合并会导致错误显示名称、错误分组和筛选串选。此前按数字 ID 合并的实现和“327 个类别”的结论已撤回。

来源快照位于 relay/javdb/tag-catalog.json，schemaVersion=2，entries 以“type:id”为键，保留原生 id、type、name；groups 保留各类型的来源分组与名称。complete=false。原始接口响应留在本机 .cache/javdb-tags-0.json 至 4.json。

## 网页词典与查询

web/src/data/javdb-tag-labels.json 以“type:id”为键，含 label/sourceNames/status，共 844 项。五种类型844项均根据用户提供的官方zh-CN网页源码核对分组与ID，繁体来源名称保存在labelTraditional，label统一为本地简体，标记simplified-zh-CN。groupLabels保存25个经核实的网页分组名，localizations分别记录五种类型的来源与覆盖范围；sourceNames保留接口原名，并追加已核实的简体名称。先前在合并身份上维护的显示别名撤回，避免把一个类型的词套给另一个类型。没有使用外部翻译服务，也没有翻译标题和评论。

作品详情接口提供数值型 type，采集保存 metadata.type，构建时投影为 javdbType。2026-10-23 已对现有31份补充记录逐一请求详情、核对原生ID与番号后回填成功，原 fetchedAt、其他元数据与评论不变，另记 typeFetchedAt。以后正常采集保留此字段；旧记录缺类型时不会因七天缓存而跳过补齐。

网页查询、显示、计数和归组优先使用 type:id；原生ID不变，简繁名称差异不再影响身份。缺类型的历史资料兼容 ID＋编码原名，旧纯数字链接保留原语义并注明。已知类型但目录缺项时列为“来源目录未收录”；现有样本发现有码40/颜射没有出现在当前目录，因此保留原文而不猜分组。

手动回填命令：node tools/backfill-work-types.js。默认最多50次请求，可设 TYPE_BACKFILL_REQUESTS（1至150）；每次间隔一秒，已齐字段直接跳过，限流停止，身份不一致不写文件。回填只读取作品详情，不下载图片或评论。

独立总表入口：网站主导航“类别目录”，路由 /tags。按来源类型、分组、类别顺序显示全部844项，支持搜索、类型切换、URL恢复和完整JSON下载。总表统一显示一列类别名称，五种类型均使用本地整理的简体名称；来源原文保存在数据中，不增加重复对照列。搜索同时匹配简体显示名、接口原名、分组和ID；JSON下载同时保留来源目录和显示词典，分组数量与本地采集覆盖无关。当前快照日期写在页面与下载中；更新来源快照时须同步日期与分组文件，不得只改数字ID词典。

目录只定义分组，数量来自当前入口的本地作品集合。没有本地作品的类别不列出，已选零数量条件保留。维护词典时，必须在对应内容类型内核对原名称，不能只凭数字 ID 修改 label。

## minnano 的观察范围

通过本机代理访问 actress_list.php 与 av_list.php，取得有效标题与 HTML。人物目录出现 112 次标签链接，按 tag_a_id 去重为 38 个。这些是当前人物条目的观察标签，不能称为全站目录。作品列表页未发现 tag/genre 链接，也不能据此断言源站没有作品类别。

minnano 人物标签与 JavDB 作品类别分别维护，不能按同名或同号自动合并。本轮没有建立 minnano 全量类别目录。

## 2026-10-24 颜射分组与同名重复条目核实

## 本地简体显示整理（2026-10-24）

官方 zh-CN 页面仍包含繁体名称，因此网页显示不再直接沿用页面字形。844 个类别与 25 个分组统一经过本地 OpenCC tw2s 转换，少量明确的日文称谓通过整词规则处理；不使用外部翻译服务。label 是简体显示名，labelTraditional 保留繁体来源名称，sourceNames 保留来源观察名称；traditionalGroupLabels 保留来源分组名，groupLabels 用于简体显示。status 为 simplified-zh-CN，displayNormalization 记录规则版本。ID、内容类型、来源分组和采集原记录不变。

修改词典后运行 `npm run labels:normalize --prefix web` 统一名称，再运行 `npm run labels:check --prefix web` 检查遗漏。转换规则位于 web/scripts/tag-label-normalization.mjs，只在开发与测试时加载，不进入网页运行包。新增有歧义的词应先核实语义再加入整词规则，不能用全局单字替换猜测含义。

## 三语字段约定（2026-10-24）

不再单设官方原名字段。label 为简体默认显示，labelTraditional 为繁体来源名称，labelEnglish 为英文；未核实的英文使用 null；当前五类目录英文已全部核实补齐。分组对应 groupLabels、traditionalGroupLabels、englishGroupLabels。sourceNames 是内部来源匹配别名，不是第四种展示语言。后续英文提取应按 type:id 和分组 ID 对齐，不能按中文名称猜测对应关系。

## 繁体与英文目录核对（2026-10-24）

使用用户保存的五类繁体与五类英文页面，只解析类别与分组字段。繁体语言标记为 zh，英文为 en；每组按内容类型和完整类别 ID 集合匹配，五类均与已有分组完全一致，类别数分别为307、151、208、55、123。844 个繁体类别名与已有来源名称完全一致；25 个繁体分组名改用本次繁体页面的实际名称，修正此前从简体分组沿用的字形。英文补齐844个类别和25个分组。欧美和动漫英文源码分别重复包含完整目录，13个重复分组逐项验证一致后去重。未保存原始登录HTML。
