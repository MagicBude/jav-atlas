# 浏览端交互规格

状态：v2 设计草案，待用户评审，未实现。日期：2026-10-22。

本文件补充[整体设计](web-design.md)，专门回答“点哪里、发生什么、如何返回、哪些内容能改、数据存在哪里”。与第一版线框有冲突时，以本文件为准。

## 1. 已选方案与理由

采用浅色资料库、分页浏览。**桌面默认右侧详情抽屉，保留完整详情页；手机默认完整详情页；收藏、个人修改、备注和个人标签在第一版支持，并保存在 localStorage。** 不打开独立浏览器弹窗，不自动新建标签页。

单用详情页容易打断连续浏览；单用中心弹窗不适合长资料和原始字段。右侧抽屉适合快速查看、收藏和查看相邻结果，完整页适合长时间查阅、编辑与分享。两种容器复用同一个人物内容组件，不维护两套资料逻辑。桌面 1024 px 起启用抽屉，宽度约 640–760 px；更窄时使用完整页。

这些是待评审的设计决定，不是已实现或已验收的功能。先评审本文件及交互线框，再开始开发。

## 2. 哪些操作换页面

顶层导航为“人物、收藏、榜单、数据说明”；个人数据导入导出放在“数据说明 → 我的本地数据”，详情编辑处也提供入口。首版不再增加单独的账号/管理系统。

- 人物：一个人物列表页。来源、性别、罩杯、身高等是该页筛选，**不是每选一个条件就进入一种新页面**。
- 收藏：独立收藏列表页，复用人物页的搜索、筛选、卡片和分页，只将候选集限制为已收藏人物。
- 榜单：独立页面；日/周/月在本页切换榜期，不弹新窗口。
- 人物详情：拥有独立 URL；同站桌面点击可呈现为列表上方的路由抽屉，直接访问该 URL 则呈现为完整页。
- 编辑本地资料：详情内部切换到编辑状态，不再叠加第二层大弹窗；仅离开未保存编辑时弹出小确认框。
- 原始资料、基本资料、相关人物：同一详情内容里的锚点区块，不分别进入新页面，不重复取同一份详情块。
- 外部来源和社交网站：普通外部链接；显式标注外部链接，默认新标签页，原站内浏览位置不变。

地址示例：人物 `/#/people?source=minnano&cup=F&page=3`；收藏 `/#/favorites?sort=added-desc`；详情 `/#/people/minnano/698899`。原始 ID 保留字符串及大小写，来源不同的收藏独立保存。

## 3. 人物列表的一次完整操作

1. 打开人物页，读取 URL 条件并加载对应来源索引；没有 URL 条件时使用默认来源 minnano、每页 48 条。
2. 输入姓名、别名或 ID，停止输入约 120 ms 后更新结果；Enter 立即提交当前输入。输入法组词期间不触发半成品查询。
3. 搜索和公共筛选更新 URL 与结果，个人筛选保存到当前会话；页码回到 1，显示结果条数和已选条件，已加载结果不被加载骨架反复清空。
4. 点击页码时更新 URL 并滚至结果区标题，不跳回页面顶栏；上一页/下一页在边界禁用。
5. 点击人物头像或姓名打开详情；点击卡片收藏星标仅切换收藏，不打开详情。卡片不使用嵌套链接包住收藏按钮。
6. 关闭详情或返回后恢复该结果列表、选项、页码、滚动位置及焦点，不重新默认排序。

搜索输入连续变更使用 replace 更新当前查询历史；翻页、顶层导航、打开详情使用 push。筛选以一次操作为一组更新，不让浏览器后退逐字撤销输入。桌面多选立即生效，区间在 Enter 或离开输入组时提交；未提交区间只是输入草稿。排序、每页数量变化同样回到第一页；卡片/列表切换尽量保留当前第一条可见人物作为锚点。

## 4. 筛选条件清单

每个筛选都要明确：选择类型、匹配规则、未知值规则、当前来源支持情况。不在首屏一次展开全部条件。

### 4.1 常用条件

- **来源**：单选 minnano / JavDB / 全部来源。JavDB 普通详情与无码集合的同 ID 在这一来源内只展示一次；跨站同名不合并。
- **收藏状态**：单选不限 / 已收藏 / 未收藏；收藏页固定已收藏，不再显示相反选项。
- **性别**：多选女 / 男 / 未知；取同维度并集，默认不限。来源证据和个人修改要分别标记。
- **身高**：最低/最高 cm，闭区间；任一端可留空。缺失值默认不匹配区间，额外提供“同时包含未知”，不把未知当 0。
- **罩杯**：多选，按已采集值生成选项，另有未知；仅规范化字母宽度/大小写，不擅自转换不同国家尺寸标准。
- **头像**：不限 / 有本地头像 / 缺头像。浏览器图片临时加载失败不改变构建时的文件存在事实，可在单条上显示重试。
- **资料阶段**：多选目录记录 / 详情已采集 / 原字段已采集 / API 资料；记录按其最高已达阶段分类，标签不写“完整”。

### 4.2 高级条件

- **出生年份**：起止年份，闭区间；只从有效生日取年，非法日期仍是未知。不把当前年龄作为静态缓存字段。
- **胸围、腰围、臀围**：分别是 cm 区间，未知策略与身高一致；只在当前索引有可用字段时启用。
- **血型**：多选来源已有值及未知；不从其他特征推测。
- **出生地**：已知值选择及可搜索选项；不直接把自由文本强制解析成国家/城市层级。
- **事务所**：可搜索多选，按规范字段/来源映射匹配；原始事务所文本和链接仍在详情保留。
- **来源标签**：多选，默认“匹配任一”，可切换“匹配全部”；来源与原生标签 ID 一起区分，不能仅凭同名字面跨站归并含义。
- **个人标签**：本地自建多选，与来源标签分开；默认匹配任一，可切换全部。
- **本地修改**：不限 / 有本地修改 / 无本地修改；便于找到待核对人物。
- **最近批次失败**：仅在“数据说明 → 最近一批 → 查看失败人物”入口携带批次限定；不作为“全站失败”筛选。

个人备注不进入公开搜索 URL，也不默认参与普通姓名搜索。首版不做任意 JSON 字段表达式、未采集作品类型筛选或跨来源统一作品数区间，避免没有依据的选项。

### 4.3 条件组合与反馈

不同维度取交集，同一多选维度取并集；标签的“全部”模式是显式例外。多个范围同时生效。来源切换后不支持的来源专属条件予以移除，并提示具体移除了哪些条件；通用条件、个人条件保留。

下拉支持“搜索选项”；候选项按其他有效条件计算可匹配数。零结果的未选项可禁用；已选的零结果项仍可取消，不能把用户困在无结果状态。当前来源根本不支持的字段显示原因；来源支持但尚无采集值显示“暂无已采集值”。

已选条件以可移除标签显示；“清空筛选”清除搜索与业务条件，保留来源、视图、每页数量。收藏页仍保留已收藏范围。手机抽屉“重置”只清空抽屉草稿，点击“查看结果”后才应用；取消、遮罩关闭不应用草稿。

区间输入非法、下限大于上限、日期不合法时显示就地错误，不静默交换数值；用户修正前沿用上一组有效查询。非法 URL 参数被规范化为可解释的默认值。

## 5. 排序与查看口径

人物页支持相关度、姓名、身高、出生日期、详情采集时间；收藏页增加最近收藏时间。姓名支持升/降序，缺失值始终排最后；最终用来源与原始 ID 稳定排序。数据中没有的排序字段不能编造。

默认按“当前显示值”筛选和排序，包含本地修改；搜索仍保留源姓名/源别名命中，防止改名后找不到来源名字。工具栏提供“当前显示值 / 仅源数据”切换，URL 用 `values=effective|source` 记录。后者排除本地覆盖值对数值、性别等筛选的影响，但收藏条件仍是本地属性。

URL 只保存公共搜索、公共筛选、排序、页码和查看口径，不包含收藏清单、备注、覆盖值或个人标签名称。个人标签、收藏状态和“有本地修改”条件保存到当前列表的 history state 与 sessionStorage，刷新本标签页可以恢复，分享不带走这些个人条件。复制链接时明确“仅分享公共条件”，私有条件省略后从第一页开始；收藏页分享只指向收藏入口，不泄露清单。换浏览器没有这些个人数据，当前显示值也可能不同。跨来源全部结果显示“来源条目数”，不当成独立人物人数。

## 6. 抽屉、完整页与新标签页

桌面点击普通人物链接时，保存背景列表位置，地址进入真实人物详情路由，以模态右侧抽屉呈现。背景列表保留实例并锁定滚动；键盘与读屏不能操作背景。抽屉内部独立滚动，标题和关闭按钮固定可达。

抽屉显示完整人物区块，不是删减资料的摘要；收藏、本地修改、原字段和来源都可访问。顶部有“完整页”入口，切换后 URL 不变、人物内容不变，仅改呈现容器，并保留当前区块；该转换 replace 当前详情历史项，返回仍到列表。

点击 X、Escape、无编辑草稿时点击遮罩、浏览器后退，均执行同一关闭动作并回到背景列表。抽屉只增加一条详情历史；在抽屉内切换相关人物或相邻人物采用 replace，后退关闭抽屉，而不是连退十个人。上一位/下一位只遍历本次结果页里的快照序列，并显示位置；到边界禁用，不突然跨页加载另一批。

Ctrl/Cmd 点击、鼠标中键、右键“新标签页打开”保留原生链接行为，直接打开完整详情页，不依赖背景列表。直接粘贴 URL、刷新详情或手机访问同一路由，也显示完整页，不凭不存在的背景状态强行弹抽屉。

独立详情页里的相关人物链接采用普通 push，后退返回上一人物；只有有合法背景列表的抽屉采用 replace，避免混淆两种历史行为。窗口宽度在详情打开期间跨越断点时只转换容器，不增减浏览历史，不丢人物或草稿。

明确示例：列表 L → 抽屉 A（push）→ 完整页 A（replace，并清除背景列表呈现状态）→ 相关人物 B（push）。在 B 按浏览器后退回完整页 A，再后退回 L；在 B 点击“返回之前的结果”则直接回到 L 的历史项，不把 A 误称为列表。A、B 都保留指向 L 的同会话返回引用与锚点，完整页呈现不再携带“打开抽屉”的背景状态。站内会话能确认目标历史项仍有效时按实际历史距离返回；不能确认时 replace 到保存的列表 URL 并恢复会话条件，不能盲目多次 back。从全新列表入口打开另一人物时建立新引用，不继承上次不相关的列表。

完整详情页的“返回列表”优先使用当前会话有效的站内返回记录，不能无条件 history.back() 把直接访问者送出网站；没有有效记录时进入对应来源人物列表。页眉另有明确的来源链接。

## 7. 如何返回到之前浏览的位置

位置恢复有三层：**URL 保存查询和页码；会话记录保存入口与锚点；页面状态保留当前已加载内容。** 不仅记录一个脆弱的 scrollY。

打开人物前，按当前列表历史项保存：规范化 URL、个人筛选草稿已应用值、来源页面（人物/收藏/榜单）、manifest 版本、页码/每页数量、第一条可见人物的来源和 ID、该条到视口的偏移、scrollY 兜底值及触发链接。不能只按 URL 索引，因为同一公共 URL 可以对应不同个人筛选。详情路由携带当前会话返回引用；返回记录存 sessionStorage，按最近 20 个列表状态淘汰，不写入分享 URL。

关闭抽屉时解锁背景滚动，保持原列表 DOM，焦点回到触发链接；触发项已不存在则聚焦邻近项或结果区标题。完整页返回时先恢复 URL 并等待索引与当前页布局就绪，再定位人物锚点；头像预留尺寸，避免图片加载后位置漂移。只恢复一次，不能用户开始滚动后又强行拉回。

若人物因取消收藏或修改后不符合筛选而离开结果，优先定位原位置的下一条，其次上一条；均不存在时回到结果区标题，显示原因。结果减少导致页码超界时定位最后有效页并同步 URL。若数据版本变化导致排序不同，尽量定位原人物；找不到时采用原页码附近及 scrollY 兜底，不声称像素绝对相同。

刷新完整详情后，会话记录仍可提供“返回之前的结果”入口；新标签页不依赖复制来的 sessionStorage 内容，也不能伪造有效返回入口。会话存储失败时仍保留 URL/页码，明确仅位置恢复降级。

## 8. 收藏人物

卡片、列表和详情均提供星标按钮，语义为收藏/取消收藏，具备按钮标签和按下状态；只点击星标不导航。所有视图共享同一份本地状态，操作成功后立即同步。收藏成功提示与失败提示必须可区分，不能先显示成功再吞掉存储错误。

收藏记录最少保存来源、原始 ID、收藏时间和更新时间；额外保留少量姓名/来源 URL 快照用于人物暂时从新数据消失时仍能识别。头像只保存路径引用，不把图片二进制或 Base64 放入 localStorage。

收藏不因源姓名变化而失效；页面优先显示当前数据，快照仅用于缺失记录的降级。源记录暂时不存在时保留收藏并标记“当前数据未收录”，仍可取消收藏、导出或访问来源。

收藏页复用全部通用筛选，增加收藏时间排序和个人标签。首版不增加多级收藏夹；用个人标签完成“待看、喜欢、待核对”等组织需求，标签由用户自建而不是预设强制分类。

个人标签的重命名同步更新该标签的关联；删除标签只移除对应标签关联，不取消收藏、不删备注。重名规范化只用于个人标签去重，不能影响源站标签或人物身份。

取消收藏提供短时“撤销”操作。收藏页移除当前行时不立即跳回顶部，按第 7 节恢复锚点。仅取消收藏**不删除备注、标签或本地资料修改**；再次收藏仍能看到原个人资料。

## 9. 人物资料能否修改

可以，首版支持**本地修改**。详情清楚区分“来源资料”和“我的修改”，默认合成显示；原始 JSON、原字段原文、来源证据和公共仓库不被浏览器改写。本地修改只影响这个浏览器的查看，不代表改正了全站数据。

允许编辑：显示名、个人别名、生日、性别、身高/三围/罩杯/鞋码、血型、出生地、爱好、事务所及允许的官网/社交链接；另可编辑个人备注、个人标签与自定义文本字段。源站 ID、来源、原始姓名记录、采集时间、证据、源站推荐关联和作品样本不可直接改写。

源站未采集的资料可以补充，但显示“本地补充”，不补造来源证据。改性别只改变个人显示值，源站性别与依据依旧可查，不能把个人值当作采集确认结果。原始字段不能在“原文”区被编辑覆盖；想订正其显示含义可用本地自定义字段，原文仍保留。

每个可编辑字段提供：当前显示值、来源值、我的值和“恢复来源”。编辑时空白表示取消该字段覆盖；如需要明确将原有值设为未知，使用单独“设为未知”动作，保存显式 null，不能把“无覆盖”和“覆盖为空”混为一谈。

保存为字段级覆盖，只保存用户真正修改的字段、编辑时看到的来源值和本地修改时间，不复制整份人物资料。姓名修改不改变 ID、头像文件路径或收藏身份。自定义字段具有个人标签与值，不混入来源原始字段列表。

每次保存只提交明确的实际改动字段集合，不能把打开表单时的整个人物快照写回。例如 A 标签页改身高、B 标签页取消收藏，A 保存只提交身高，必须保留 B 的最新取消状态；编辑没有涉及的备注、标签和收藏都不得被旧表单回写。“确认覆盖”也只授权所列冲突字段，不授权覆盖整个人物。

编辑有明确的“保存”“取消”；Ctrl/Cmd+S 在编辑表单内执行保存，不能误触发浏览器保存网页。非法日期、非法数字范围或不支持的链接协议应就地提示。备注按纯文本保存；外链只接受 http/https，不执行任意 HTML。

保存成功后显示本地标记，详情、列表、搜索和筛选使用相同覆盖模型。保存失败保留表单草稿、说明原因，不假装保存完成。单字段恢复、单人物恢复和清空全部本地修改是不同操作；批量清空前确认范围，不同时取消收藏。

## 10. 草稿、关闭与源站更新冲突

编辑未保存时，关闭详情、切换人物、回列表、切导航、Escape 和浏览器后退都经过同一个离开保护：保存后离开 / 放弃修改 / 继续编辑。保存失败则留在编辑状态。刷新或关闭浏览器标签页使用浏览器允许的离开提醒，不承诺浏览器一定展示自定义文字。

首版不持久化每次键入的草稿，不自动保存字段，避免把临时输入混成正式资料。收藏和标签独立快速操作只有在成功写入后才算保存；处于人物编辑表单内的标签调整则随该次保存提交，不出现两种按钮含义混杂。

采集更新后，未被本地改过的字段自动使用新源值；被改过的字段继续使用个人值，同时比较当前源值与编辑时记录的源值。不同则标记“来源已更新，需核对”，展示三者，提供保留我的值 / 使用新来源值；保留个人值时更新其对照基线。不能静默丢弃个人修改，也不能悄悄把新源资料覆盖回旧快照。

人物原始 ID 或来源改变时不自动迁移个人资料，不按名字猜测。旧收藏/修改保持可导出；后续如需要手动转移，应独立设计确认过程，不夹带在数据更新中自动执行。

## 11. 本地数据的存储与备份

持久数据仅为收藏、字段覆盖、个人标签、自定义字段、备注和少量查看偏好；完整名册、详情块、原始 JSON 与头像不放 localStorage。会话返回位置存 sessionStorage；已加载目录/详情的请求缓存放内存，不占据个人数据存储。

个人资料建议使用一个带应用前缀与版本的存储键 `jav-atlas:user-data:v1`，内容包含 schemaVersion、updatedAt 和按来源/原始 ID 组织的用户记录。人物记录内再区分 favorite、overrides、note、personalTags、customFields。来源和 ID 是原生身份组合，不另造人物编号。视图偏好单独用 `jav-atlas:preferences:v1`，导出时可选带上。

localStorage 以站点 origin 为边界：本地开发地址与正式域名、不同浏览器或设备的数据不自动互通。清理站点数据可能删除收藏。界面在“我的本地数据”中明确这一点，并提供导出/导入，不要求用户登录。

每次写入捕获不可用、权限拒绝、配额不足与 JSON 损坏。浏览器配额有限，不能把 5 MB 当作应用可保证使用的空间。写入失败则回滚已显示的收藏状态或保留编辑草稿，提示导出备份/释放空间；浏览、搜索和源资料查看仍可用。

读取到不支持的更高 schemaVersion 或损坏数据时不自动覆盖原键。提供导出原始存储文本和显式重置选项。模式升级采用验证、迁移、再写入的流程；旧数据在成功前不能被破坏，不能因新增功能清空收藏。

标签页通过 storage 事件同步。写入前重新读取最新版本，仅应用实际改动字段，减少无关数据互相覆盖；storage 不是事务锁，不能承诺两个标签页真正同时写入绝对无冲突。外页变更未编辑字段时合入已保存状态，不改本页草稿；同一正在编辑字段发生冲突时保留草稿，列出该字段的新值，再选择重新载入或确认覆盖。确认执行前再次读取并核对所确认版本，若该字段又变化则重新提示，不能拿一次确认覆盖后来出现的不同内容。

导出按钮生成带 formatVersion、exportedAt、应用标识和用户记录的 JSON；默认导出所有个人数据，不包含整站资料或图片。允许只导出收藏，但要说明它不包含修改。文件名带日期，导出不清空数据。

导入先校验格式、来源、ID、字段类型、链接协议与合理大小，再预览新增、冲突和无效记录数量；不读取文件中的任意路径、不执行代码。对同一来源/ID：不冲突的字段合并，冲突让用户选择保留本地或使用导入，整次操作可取消。默认不提供一键静默覆盖全部；替换模式必须确认并先提供旧数据备份。导入时间戳不能作为自动覆盖可信依据。

导入含已收藏记录但本地已取消收藏时，算明确冲突，不悄悄复活；需保留无收藏状态但仍有备注/修改的记录。实现时为取消动作保留简短更新时间标记，以支持该判断，不需要引入完整操作日志或云同步系统。

删除个人内容也要保留最小的当前状态标记：收藏有 true/false 与操作时间；覆盖字段区分从未改过、set（含显式 null）和 clear（已恢复来源）；清空备注、删除自定义字段/标签关联同样保留 clear 标记。clear 不影响当前源值显示，但参加导入冲突判断并随备份导出，防止“改身高 → 导出旧备份 → 恢复来源 → 导入旧备份”静默复活旧身高。批量恢复只为曾改动字段设置 clear，不给所有源字段制造记录；这不是完整操作历史。

导入预览和确认都按字段或标签关联列出冲突，保留未选择覆盖的最新字段。确认执行时重新读取本地版本；若预览之后其他标签页改变了相关字段，则重新预览，不用过时快照整份覆盖。显式清空全部个人数据会删除这些标记，界面需说明旧备份之后可以恢复旧内容；该操作须单独确认，不等同于“清空筛选”。

## 12. 典型边界与用户反馈

- 刚收藏的人被另一来源同名记录混淆：按来源+原始 ID 区分，收藏页显示来源徽标。
- 编辑后不符合当前筛选：详情保存并解释“此人物已不符合当前条件”；返回列表定位邻近记录，不把保存误报为失败。
- 收藏页取消当前唯一人物：显示收藏空状态和返回浏览入口，允许撤销；不留下失效页码。
- 从榜单打开详情：关闭或返回恢复榜期、排名位置；不一律返回人物首页。
- 复制抽屉地址发给别人：接收方看到完整详情页，不尝试还原发起者的背景列表或私人收藏。
- 原始资料未采集：详情仍可打开，显示目录信息与来源入口，本地补充与收藏均可用。
- 旧版本详情文件失效：提示站点已更新并保留当前人物 URL 与本地数据，不把它当作人物被删除。
- 导出后迁移到新域名：手动导入完成转移；没有服务端同步，不显示“已同步到所有设备”。
- 卡片图片失败：占位与重试不影响收藏、打开详情或搜索。
- 长姓名、很多别名/标签：摘要可省略，详情可换行与完整展开，不删原始数据。

## 13. 模块与状态归属

在整体设计的目录上增加 `features/favorites`、`features/personal-data` 与 `data/local`。本地存储读写只能经过 personalDataRepository；组件不能分散直接拼 localStorage key。源数据 repository 保持只读，二者通过明确的 `resolvePerson(sourceRecord, localOverrides)` 纯函数组合。

sourceRecord、localOverrides、effectivePerson 是三个明确模型；原始资料组件只收 sourceRecord，卡片/常规详情与筛选收 effectivePerson。字段定义集中描述展示名、类型、可编辑性、校验和筛选能力，减少详情、编辑器和筛选三处不一致；不实现任意插件或动态代码执行系统。

状态划分：URL 管公共查询/排序/页码/偏好视图；localStorage 管已保存个人数据；sessionStorage 与 history state 管返回记录和个人筛选；内存管加载缓存、抽屉背景、未保存草稿和一次性撤销。没有必要为这些状态立刻引入 Redux 或数据库。

当本地资料变化时，按受影响人物更新展示索引并重算结果；不能只改详情而让卡片仍旧值。源数据切换版本时重新合成，个人覆盖不因构建更新丢失。UI 层不修改 adapter 结果对象，避免一次编辑污染多个来源视图。

## 14. 开发前必须能回答的验收场景

以下均为待实现的验收用例，不是已经跑过的测试：

1. 第 3 页滚动到中间 → 打开人物 → 关闭抽屉：条件、页码、位置与焦点一致。
2. 同一步骤在手机完成，或桌面切完整页再返回：同样恢复；图片晚到不推动定位。
3. 抽屉内切换 5 人后浏览器后退：回原列表，不必后退 5 次。
4. 新标签页/复制地址/刷新详情：完整页可用，返回按钮不会跳出站点。
5. 从榜单和收藏页进入人物：分别回原榜单位置和收藏位置。
6. 来源+性别+身高+罩杯同时筛选，未知值和任一/全部标签规则正确，URL 可刷新还原。
7. 人物页收藏后，收藏页及详情立即一致；刷新仍在；来源不同同名人物不串记录。
8. 收藏页取消、撤销、最后一条取消，页码与邻近定位都正确；备注和本地修改不被顺带删除。
9. 修改身高后保存：卡片、详情和筛选同步；原始来源字段与原始 JSON 不变。
10. 恢复来源、设为未知、取消编辑是三种不同结果；原始姓名和 ID 不受个人显示名影响。
11. 编辑未保存后关闭、后退、切人或切导航：不会静默丢草稿；保存失败仍停留编辑。
12. 源数据更新与本地修改冲突：出现三值对照，用户可选保留或恢复，不自动删改。
13. localStorage 被禁用/写满/内容损坏：不假报保存成功，源资料浏览仍正常，不自动覆盖原始存储。
14. 导出导入含冲突记录、已取消收藏记录和缺失源人物：有预览，可取消，结果可追溯。
15. 两标签页同时打开，外部修改不悄悄覆盖当前草稿；刷新后恢复已保存数据。
16. 抽屉焦点受限、Escape 可关闭、返回焦点正确；未保存编辑时先经过离开保护。
17. 修改身高后导出 → 恢复来源 → 导入旧备份：旧覆盖值作为冲突展示，不静默复活；备注和标签删除亦然。
18. A 编辑身高、B 取消收藏 → A 保存：身高保存且仍未收藏，未改字段使用最新状态。
19. 使用个人标签筛选后复制链接：链接不含标签名、备注或收藏清单，明确只分享公共条件并从第一页开始。
20. 列表 L → 抽屉 A → 完整页 A → 相关人物 B：浏览器后退到 A，返回结果按钮直接回 L，位置恢复正确。
