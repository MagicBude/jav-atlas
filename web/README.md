# JAV Atlas 浏览端

浅色人物资料库，使用 React、TypeScript 和 Vite。收藏、个人修改、备注与标签保存在当前浏览器的 localStorage；来源数据只读。

## 启动与检查

建议使用 Node.js 24，在 `web` 目录执行：

```powershell
npm ci
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173/。启动前从仓库已有的 `relay` 生成浏览资源，不访问源站，也不启动采集。更换数据后重新启动即可。

```powershell
npm test
npm run build
npm run preview -- --port 4173
```

构建产物在 `dist`。部署到仓库子路径时，设置环境变量 `BASE_PATH=/jav-atlas/` 再构建。Hash 路由不要求静态主机配置人物详情重写规则。Actions 中的浏览端检查工作流只检查、构建和提供产物下载，目前不自动发布网站。

## 使用方式

- 人物页支持来源切换、姓名/别名/ID 搜索、组合筛选、分页和紧凑视图。
- 宽屏详情使用带独立地址的抽屉，也能切换完整页面；窄屏直接显示完整页。返回保留筛选、页码和浏览位置。
- 详情可查看规范字段、来源依据、原始标签和完整原记录。已采集的 `agency`、`rel`、`profileFields` 等不会因为展示映射而丢失。
- 收藏支持撤销，个人修改支持设值、标记未知及恢复来源；有草稿时离开会提示，同字段跨标签页修改需要确认。
- 数据说明页提供覆盖情况、原始下载、本地备份导入导出、冲突预览与标签整理。

个人数据按站点地址隔离：本地开发地址、正式网站、其他浏览器不会自动共享收藏。迁移前导出备份，再到目标站点导入。清理浏览器存储会清除个人数据。个人备份不包含公开全库与照片。

## 阅读与扩展

先读 [新手阅读指南](LEARNING.md)。`scripts` 生成数据，`src/entities` 定义模型，`src/data` 管理读取与持久化，`src/app` 管理共享状态和路由，`src/features` 实现功能模块，`src/pages` 组合页面，`src/shared` 提供通用组件。关键行为测试在 `tests`。

当前是第一版实现，自动检查与实际操作分别记录于 [验证记录](../docs/validation.md)，整体体验待用户验收。交互依据：

- [浏览端设计方案](../docs/web-design.md)：布局、数据语义、模块边界、构建加载、实施顺序与验收。
- [交互规格](../docs/web-interactions.md)：筛选条件清单、页面/抽屉、返回定位、收藏、本地编辑、导入导出与异常处理。
- [交互线框](../docs/design/web-interactions.png)：桌面详情抽屉、本地编辑和收藏页的具体操作。
- [布局线框](../docs/design/web-wireframes.svg)：桌面列表、人物详情、手机列表与筛选抽屉。示意信息不是实时数据。

保留源站 ID、完整已采集字段及来源，原始采集 JSON 不因展示而精简。生成目录与依赖不提交 Git。

## 榜单人物范围

当前 minnano 默认只生成 ranked-pool.json 中曾上榜人物的索引、详情与头像资源。完整历史名册保留在原始下载快照和 relay 中，不再作为日常展示或采集范围。相关人物仍可利用存档姓名补全显示，但不会递归加入采集池。详情页独立地址若不在当前池内，会显示未收录；已有收藏快照保留。

## 作品浏览试用

作品区按实际采集结果接入，以生成的manifest为准，不是全人物池作品库。进入人物详情点击“作品”直接切换到列表，支持标题/番号搜索、年份与厂商筛选、每页24项、按日期或评分排序。基本资料、作品、相关人物、我的资料及原始资料一次只展示一个分区，section写入URL，切换保留作品条件。点击作品弹出详情，独立地址为 `#/works/minnano/<作品ID>`；原始字段可展开。未知作品占位单独折叠，不计入正式作品。作品使用URL中的wq/wy/wm/wp/ws/work参数，避免与人物列表分页混用。已发现但尚无详情的作品提供来源页入口。

当前先用紧凑文字列表，不下载封面、不增加作品收藏或编辑。浏览器已实测新增人物列表、详情返回和未知占位展示；用户最终验收仍待进行。

作品详情的JavDB补充目前包括原3部样本及基础元数据试采新增8部；评论仍只在原3部保留。页面分开展示两站资料及日期差异，短评显示实际保存条数和快照时间，不代表全部评论；无元数据/评论定时刷新。阅读改进方案见docs/web-reading-v3.md，区分已实现内容与后续规划。

## 独立作品库与全局搜索

导航“作品”进入#/works，支持标题/番号、人物、年份和厂商筛选，以及日期/评分排序、标准/紧凑密度。它与人物作品区共用WorkBrowser，work查询参数打开同一详情层，关闭时保持背景结果。独立作品详情地址仍是#/works/minnano/ID。

顶部搜索提交到#/search?q=关键词，按人物和作品分组展示本地结果。人物查姓名/别名/原生ID，作品查标题/番号；没有结果不代表源站不存在。当前没有输入时自动建议。数据说明仍从页脚进入。所有查询只读本地资源，不发起采集。
