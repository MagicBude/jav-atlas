当前仅完成设计草案，尚无前端实现。用户选择浅色资料库风格；设计确认前不创建源码或安装依赖。

- [浏览端设计方案](../docs/web-design.md)：布局、数据语义、模块边界、构建加载、实施顺序与验收。
- [交互规格](../docs/web-interactions.md)：筛选条件清单、页面/抽屉、返回定位、收藏、本地编辑、导入导出与异常处理。
- [交互线框](../docs/design/web-interactions.png)：桌面详情抽屉、本地编辑和收藏页的具体操作。
- [布局线框](../docs/design/web-wireframes.svg)：桌面列表、人物详情、手机列表与筛选抽屉。示意信息不是实时数据。

建议使用 React + TypeScript + Vite，浏览资源从 relay 只读生成。保留源站 ID、完整已采集字段及来源，原始采集 JSON 不因展示而精简。
